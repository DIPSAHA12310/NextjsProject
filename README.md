
# FITLOG - Exercise Library

FITLOG is a fitness website where users can explore exercises, view exercise details, create a daily workout plan, and save their favorite exercises.

## Features

- Browse exercises from the library.
- View individual exercise details.
- Add exercises to today's plan.
- Save favorite exercises.
- Prevent duplicate exercises.
- Remove exercises from the plan and saved list.
- Mark exercises as completed.
- Track plan progress and workout information.
- Store plan and saved data in localStorage.
- Display toast notifications for user actions.
- Responsive user interface.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Toastify

## Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd YOUR_PROJECT_FOLDER
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
